# Черным по белому — Порошковая покраска металла

## 1. Описание проекта
Сайт компании «Черным по белому», специализирующейся на порошковой покраске металлических изделий. Целевая аудитория — частные клиенты и бизнес-заказчики, которым нужна качественная покраска металлоконструкций, дисков, деталей. Сайт выполняет роль визитки и инструмента привлечения заявок.

## 2. Структура страниц
- `/` — Главная (одностраничный сайт со всеми секциями: Hero, Услуги, Преимущества, Галерея, Прайс, Отзывы, Заявка, Контакты)

## 3. Основные функции
- [ ] Hero-секция с видео процесса покраски
- [ ] Секция услуг и описания компании
- [ ] Секция преимуществ (сетка карточек)
- [ ] Галерея работ + Прайс-лист
- [ ] Отзывы клиентов
- [ ] Форма заявки (CTA)
- [ ] Футер с контактами и подпиской

## 4. Модель данных
База данных не требуется на данном этапе.

## 5. Сторонние интеграции
- Форма заявки: Readdy Forms (get_form_url)

## 6. План разработки

### Фаза 1: Главная страница (все секции)
- Цель: Полноценный лендинг со всеми секциями
- Результат: Готовая главная страница с навигацией, hero, услугами, преимуществами, галереей, прайсом, отзывами, формой заявки и футером
